# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Graph Horizon.
Older releases and untagged development snapshots may be used to reproduce an
issue, but they are not maintained as separate security-support branches.

## Reporting A Vulnerability

Use GitHub's private vulnerability reporting for this repository when it is
available. Include affected versions, prerequisites, impact, a minimal
reproduction, and any suggested remediation. Remove model files, credentials,
personal paths, chat content, and other unrelated sensitive data.

Do not open a public issue for an undisclosed vulnerability. If private
reporting is unavailable, do not include exploit details in a public channel;
open a minimal issue asking the maintainer to enable or provide a private
security contact.

Please allow the maintainer time to reproduce and assess the report before
public disclosure. No fixed response or remediation deadline is promised.

Ordinary installation, compatibility, and usage questions belong in the
[support policy](SUPPORT.md).
