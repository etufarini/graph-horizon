# Support

Before requesting help, review:

- the [installation guide](docs/installation.md);
- the [runtime option reference](docs/command-line/runtime-options.md);
- the [supported model and format contract](docs/supported-models-and-formats.md);
- the complete [documentation index](docs/README.md).

For reproducible defects, open a GitHub issue and include the Graph Horizon
version, operating system, selected build backend, model family and size,
command with secrets and personal paths removed, expected behavior, and the
short normalized error message. Do not upload models, credentials, bearer-token
files, personal transcripts, or generated archives.

Security vulnerabilities must not be reported in a public issue. Follow
[SECURITY.md](SECURITY.md) instead.
